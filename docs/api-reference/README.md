# API reference

Request and response schemas for platform-api, grouped by capability.

Paths are relative to the API root. The default root is `/medtronics-api`. Example: `GET /medtronics-api/ready`. Canonical route names are in [Route index](endpoints.md).

ai-runtime `/internal/*` routes are private. Devices do not call them.
